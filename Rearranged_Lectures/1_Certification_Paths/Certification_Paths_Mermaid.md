# Azure Certification Paths

1. Developer

- AZ 900 (Fundamentals)-> Azure Developer Associate (AZ 204)/AI 200 -> Azure Developer Expert (AZ 400)

2. Administrator

- AZ 900 (Fundamentals)-> Azure Administrator Associate (AZ 104) -> Azure Administrator Expert (AZ 305)

3. Solutions Architect

- AZ 900 (Fundamentals)-> Azure Solutions Architect Associate (AZ 305) -> Azure Solutions Architect Expert (AZ 400)

4. DevOps Engineer

- AZ 900 (Fundamentals)-> Azure DevOps Engineer Expert (AZ 400)

5. Security Engineer

- AZ 900 (Fundamentals)-> Azure Security Engineer Associate (AZ 500) -> Azure Security Engineer Expert (AZ 400)

6. Data Engineer

- AZ 900 (Fundamentals)-> Azure Data Engineer Associate (DP 203) -> Azure Data Engineer Expert (AZ 400)

7. Database Administrator

- AZ 900 (Fundamentals)-> Azure Database Administrator Associate (DP 300) -> Azure Database Administrator Expert (AZ 400)
