# Azure Arc

Azure Arc extends Azure management and governance capabilities to resources outside Azure. This includes on-premises servers, multi-cloud resources, and Kubernetes clusters.

## What Azure Arc Does

- Brings non-Azure resources into Azure's management experience.
- Helps apply policies, monitoring, and governance consistently.
- Supports hybrid and multi-cloud operations.

## Common Use Cases

- Managing on-premises servers through Azure.
- Applying Azure Policy to Kubernetes clusters.
- Centralizing governance across different environments.

## Why It Matters for AZ-900

- It is a strong example of Azure's hybrid cloud strategy.
- It shows that Azure management can extend beyond Azure datacenters.

## Exam Focus

- Azure Arc is about management and governance extension.
- It supports hybrid and multi-cloud scenarios.
- It does not mean the external resources physically run inside Azure.
