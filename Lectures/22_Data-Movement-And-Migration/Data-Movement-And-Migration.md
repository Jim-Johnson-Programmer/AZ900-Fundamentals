# Data Movement and Migration

Azure includes several services that help move data into, out of, and between environments. AZ-900 focuses on understanding which tool fits online transfer, offline transfer, or broader migration scenarios.

## Common Approaches

- Online transfer uses the network to move data directly.
- Offline transfer uses physical devices when bandwidth is limited.
- Migration services help assess, plan, and move workloads into Azure.

## Key Azure Services

- Azure Migrate helps discover, assess, and migrate servers, databases, and applications.
- Azure Data Box supports large offline data transfers.
- AzCopy and Azure Storage Explorer help move data into storage accounts.

## Exam Focus

- Use Azure Migrate for structured migration planning.
- Use Data Box when network transfer is too slow or impractical.

Azure includes services for moving data into, out of, and between environments. Migration services help organizations move workloads from on-premises or other clouds into Azure.

## Data Movement Concepts

- Online transfer uses network connectivity.
- Offline transfer can use shipped devices for large datasets.
- Replication can help keep source and target environments synchronized.

## Relevant Azure Services

- Azure Migrate helps assess and migrate servers, databases, and applications.
- Azure Data Box helps transfer very large amounts of data offline.
- Azure Storage tools support uploads, sync, and replication scenarios.

## Exam Focus

- Know that Azure Migrate supports discovery, assessment, and migration.
- Recognize Data Box as the offline large-scale data transfer option.
