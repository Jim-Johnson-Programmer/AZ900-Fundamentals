# Azure Firewall

Azure Firewall is a managed, stateful network security service that helps control traffic between networks and to or from the internet.

## What It Provides

- Centralized rule management.
- Network and application rule filtering.
- Built-in high availability and scale.

## When It Fits

- Organizations needing more advanced centralized filtering than NSGs alone provide.
- Hub-and-spoke or enterprise network topologies.

Azure Firewall is a managed, stateful network security service that filters traffic across Azure network resources. It is more feature-rich than a simple NSG and is designed for centralized control.

## Main Capabilities

- Inbound and outbound traffic filtering.
- Central rule management.
- Application and network rule support.
- Logging and threat intelligence integration.

## Compare to NSGs

- NSGs are basic distributed traffic filters at subnet or NIC level.
- Azure Firewall is centralized and designed for broader network protection.

## Exam Focus

- Use Azure Firewall for centralized network security.
- Use NSGs for simpler traffic filtering within VNets.
