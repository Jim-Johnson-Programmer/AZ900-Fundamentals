# Zero Trust

Zero Trust is a security model based on the idea of never trusting by default and always verifying explicitly. Access decisions should consider identity, device state, location, workload, and risk.

## Core Principles

- Verify explicitly.
- Use least privilege access.
- Assume breach.

## Practical Effects

- Strong identity controls.
- Conditional access and MFA.
- Reduced broad, permanent permissions.

## Exam Focus

- Zero Trust is a mindset and strategy, not a single Azure product.
