# Azure Resource Manager and Bicep Templates

Azure Resource Manager templates and Bicep files are used to define Azure infrastructure declaratively. This allows repeatable, version-controlled deployments.

## Benefits

- Consistent deployment outcomes.
- Easier reuse across environments.
- Better auditability and collaboration.

## ARM vs Bicep

- ARM templates are typically JSON based.
- Bicep provides simpler, more readable syntax.
- Bicep compiles to ARM templates.

## Exam Focus

- ARM is the underlying deployment system.
