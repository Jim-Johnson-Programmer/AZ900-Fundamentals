# Azure Directory Services

Azure directory-related services span cloud identity and, in some cases, managed domain capabilities. AZ-900 generally focuses on understanding cloud identity versus traditional directory concepts.

## Common Concepts

- Cloud identity with Microsoft Entra ID.
- Managed domain scenarios for legacy applications when needed.
- Integration between on-premises and cloud identity systems.

## Exam Focus

- Distinguish Entra ID from classic Active Directory Domain Services.

Azure directory-related services help manage identities, authentication, and domain-compatible capabilities. Different services solve different identity needs.

## Main Concepts

- Entra ID manages cloud identities.
- Azure AD Domain Services provides managed domain capabilities such as domain join and LDAP support for certain legacy scenarios.

## When This Matters

- Some older applications expect domain services.
- Cloud-first applications often use Entra ID directly.

## Exam Focus

- Distinguish Entra ID from domain services.
- Use managed domain services when legacy compatibility is needed.
