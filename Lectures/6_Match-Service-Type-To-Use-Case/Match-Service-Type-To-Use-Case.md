# Match Service Type to Use Case

AZ-900 expects you to identify which class of cloud service best fits a business or technical need. The key is to match the level of control required against the amount of management you want Azure to handle.

## IaaS Use Cases

- Lift-and-shift workloads.
- Full control over operating systems and virtual machines.
- Custom legacy applications.

## PaaS Use Cases

- Application development without managing underlying servers.
- Web apps, APIs, databases, and managed runtime environments.
- Faster deployment with less maintenance.

## SaaS Use Cases

- Ready-to-use software delivered over the internet.
- Email, collaboration, CRM, and productivity applications.
- Minimal infrastructure management by the customer.

## Exam Focus

- If the requirement emphasizes control, think IaaS.
- If the requirement emphasizes developer productivity, think PaaS.
- If the requirement emphasizes using software immediately, think SaaS.
