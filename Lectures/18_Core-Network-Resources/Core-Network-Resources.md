# Core Network Resources

Azure networking services connect resources securely and efficiently. AZ-900 expects you to recognize the purpose of common networking components.

## Core Concepts

- Virtual networks provide isolated network environments in Azure.
- Subnets divide a virtual network into smaller segments.
- Public IP addresses allow internet connectivity.
- Network security groups filter allowed and denied traffic.

## Related Services

- VPN Gateway connects on-premises networks to Azure.
- ExpressRoute provides private dedicated connectivity.
- Load Balancer distributes traffic across resources.
- DNS translates names to IP addresses.

## Exam Focus

- A virtual network is the basic Azure networking building block.
- ExpressRoute is private connectivity, while VPN commonly uses the internet.
- Security groups are used to control network traffic.
