# Azure Advisor

Azure Advisor provides personalized best-practice recommendations for Azure resources. It analyzes deployments and suggests improvements related to cost, security, reliability, performance, and operational excellence.

## What It Helps With

- Identifying underused resources.
- Recommending resiliency improvements.
- Surfacing security and performance guidance.

## Recommendation Areas

- Reliability
- Security
- Performance
- Operational excellence
- Cost

## Exam Focus

- Azure Advisor gives recommendations, not enforcement.
