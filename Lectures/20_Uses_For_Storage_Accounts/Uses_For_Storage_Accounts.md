# Uses for Storage Accounts

An Azure storage account provides a namespace for Azure Storage services. It can support several data storage types depending on the workload.

## Main Storage Services

- Blob storage for unstructured object data.
- File storage for shared file access.
- Queue storage for simple messaging.
- Table storage for NoSQL key-value data.

## Common Use Cases

- Storing backups, images, documents, and logs.
- Hosting static website content.
- Sharing files across systems.
- Supporting asynchronous processing with queues.

## Why It Matters

- Storage accounts are foundational to many Azure solutions.
- Different storage types serve different performance and access needs.

## Exam Focus

- Know the difference between blobs, files, queues, and tables.
- Match each storage type to a simple use case.
- Understand that the storage account is the parent resource.
