# Resource Locks

Resource locks help prevent accidental changes or deletion of important Azure resources.

## Lock Types

- Delete lock prevents deletion.
- Read-only lock prevents changes and deletion.

## Why They Matter

- Useful for critical shared resources.
- Helps avoid mistakes during administration.

## Exam Focus

- Locks protect resources from accidental modification.
