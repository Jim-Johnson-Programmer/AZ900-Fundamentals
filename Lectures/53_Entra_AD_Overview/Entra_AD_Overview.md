# Entra ID Overview

Microsoft Entra ID, formerly Azure Active Directory, is Microsoft's cloud identity and access management service. It provides authentication, authorization, and identity governance capabilities.

## What It Supports

- User and group identities.
- Application identity integration.
- Single sign-on and multi-factor authentication.

## Why It Matters

- Central identity is a core cloud security control.
- Many Azure services rely on Entra ID for access management.
