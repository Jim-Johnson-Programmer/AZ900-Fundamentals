# DevOps Technologies

DevOps combines development and operations practices to improve delivery speed, quality, and automation. Azure provides services that support source control, pipelines, testing, and deployment.

## Key Concepts

- Continuous integration builds and tests changes frequently.
- Continuous delivery or deployment automates release steps.
- Infrastructure as code improves consistency and repeatability.

## Azure Services to Know

- Azure DevOps for boards, repos, pipelines, test plans, and artifacts.
- GitHub can also integrate closely with Azure deployment workflows.
