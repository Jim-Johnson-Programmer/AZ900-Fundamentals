# Cloud Adoption Framework

The Cloud Adoption Framework is Microsoft's guidance for planning and executing cloud adoption. It covers strategy, governance, architecture, operations, and migration practices.

## Main Themes

- Define business outcomes.
- Plan landing zones and governance.
- Migrate and modernize workloads.
- Manage and optimize over time.

## Exam Focus

- The framework is guidance, not a single Azure service.
