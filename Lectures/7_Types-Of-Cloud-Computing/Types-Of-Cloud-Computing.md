# Types of Cloud Computing

Cloud deployment models describe where workloads run and how resources are managed. The main types for AZ-900 are public cloud, private cloud, and hybrid cloud.

## Public Cloud

- Resources are owned and operated by a cloud provider.
- Delivered over the internet.
- Offers high scalability and fast provisioning.

## Private Cloud

- Cloud environment dedicated to a single organization.
- May be hosted on-premises or by a provider.
- Offers more direct control and customization.

## Hybrid Cloud

- Combines on-premises or private infrastructure with public cloud services.
- Supports gradual migration, compliance needs, and workload flexibility.
- Azure Arc and similar technologies help manage hybrid resources.

## Exam Focus

- Public cloud prioritizes agility and scale.
- Private cloud prioritizes control.
- Hybrid cloud balances both and is common in real-world enterprises.
