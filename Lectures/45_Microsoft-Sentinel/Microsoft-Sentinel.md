# Microsoft Sentinel

Microsoft Sentinel is a cloud-native security information and event management, or SIEM, and security orchestration, automation, and response, or SOAR, solution.

## What It Does

- Collects security-relevant data from many sources.
- Helps detect threats and suspicious behavior.
- Supports investigation and automated response workflows.

## Why It Matters

- Centralizes security monitoring.
- Helps security teams correlate events across environments.

## Exam Focus

- Sentinel is for security analytics and incident response.
