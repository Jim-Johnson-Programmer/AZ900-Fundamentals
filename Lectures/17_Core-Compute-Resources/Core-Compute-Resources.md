# Core Compute Resources

Azure compute services provide processing power for applications, workloads, and services. AZ-900 focuses on understanding the purpose of the major compute options rather than advanced configuration.

## Major Compute Options

- Virtual Machines for full control.
- App Service for managed web app hosting.
- Azure Functions for serverless event-driven execution.
- Containers and Kubernetes for portable, scalable workloads.
- Virtual Desktop for remote desktops and apps.

## Choosing the Right Service

- Choose VMs when you need operating system control.
- Choose App Service for web applications and APIs with less infrastructure management.
- Choose Functions for event-driven or short-lived workloads.
- Choose containers when portability and packaging consistency matter.

## Exam Focus

- Know the purpose of each core compute service.
- Be able to match workload needs to the right compute model.
- Understand the tradeoff between control and managed convenience.
