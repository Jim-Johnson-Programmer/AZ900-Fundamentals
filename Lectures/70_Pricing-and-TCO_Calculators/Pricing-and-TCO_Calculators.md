# Pricing and TCO Calculators

Microsoft provides calculators to estimate Azure spending and compare cloud costs against on-premises environments.

## Main Tools

- Pricing Calculator estimates Azure service costs.
- Total Cost of Ownership, or TCO, Calculator compares Azure with on-premises cost scenarios.

- Pricing Calculator estimates future Azure spend.

Azure provides calculators to estimate cloud costs and compare them with on-premises costs.

- Estimates expected Azure service costs.
- Useful for planning future deployments.

## TCO Calculator

- Compares total cost of ownership between current environments and Azure.
- Useful for migration and business case discussions.

- Pricing Calculator estimates Azure spend.
