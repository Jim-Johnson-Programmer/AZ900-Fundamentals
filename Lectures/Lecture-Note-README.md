# Lecture Note README

[AZ-900 Azure Fundamentals - John Savill](https://www.youtube.com/playlist?list=PLlVtbbG169nED0_vMEniWBQjSoxTsBYS3)

## Purpose

This Lectures folder tracks notes by topic from the AZ-900 video series. Each numbered folder contains a single markdown file for that lecture topic so the structure stays easy to scan and expand over time.

## Conventions

- Keep one main markdown file per lecture folder.
- Use the folder topic as the markdown title.
- Prefer short concept summaries, service comparisons, and exam-focused takeaways.
- Add links to Microsoft Learn or other reliable references when useful.

## Suggested Note Format

- Topic overview
- Key services or concepts
- Common exam distinctions
- Short examples or decision rules
- Follow-up links

## Suggested Usage

- Review the note before watching the lecture to prime the topic.
- Add examples or screenshots after watching.
- Mark confusing topics for later review in Microsoft Learn.
