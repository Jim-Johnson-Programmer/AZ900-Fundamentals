# Key Vault

Azure Key Vault stores and controls access to secrets, keys, and certificates. It helps applications avoid hardcoding sensitive values in code or configuration files.

## What It Stores

- Secrets such as passwords and connection strings.
- Cryptographic keys.
- Certificates.

## Benefits

- Centralized secret management.
- Access control and auditing.
- Better security practices for applications and automation.

## Exam Focus

- Key Vault is the standard service for protecting secrets and keys.
