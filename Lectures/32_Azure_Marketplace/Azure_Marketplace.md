# Azure Marketplace

Azure Marketplace is an online catalog of solutions and services that can be deployed into Azure. It includes Microsoft offerings as well as third-party software, appliances, and templates.

## What You Can Find

- Prebuilt virtual machine images.
- Security, networking, and monitoring solutions.
- Databases, developer tools, and line-of-business software.

## Why It Helps

- Reduces setup time.
- Makes it easier to deploy tested partner solutions.
- Supports pay-as-you-go and bring-your-own-license style purchasing in some cases.

## Exam Focus

- Azure Marketplace is for finding and deploying solutions.
