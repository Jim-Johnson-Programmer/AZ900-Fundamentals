# Microsoft Defender for Cloud

Microsoft Defender for Cloud is a cloud security posture management and workload protection service. It helps assess security configuration and surface threats across Azure and some hybrid or multi-cloud resources.

## Main Capabilities

- Security recommendations.
- Regulatory compliance views.
- Threat protection for supported workloads.

## Why It Matters

- Helps teams improve security posture over time.
- Centralizes cloud security insights.

## Exam Focus

- Defender for Cloud provides posture and protection guidance.
