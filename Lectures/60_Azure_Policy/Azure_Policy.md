# Azure Policy

Azure Policy is used to define, assess, and enforce organizational standards across Azure resources.

## What It Does

- Audits resources for compliance.
- Denies noncompliant deployments when configured to do so.
- Helps standardize environments.

## Common Uses

- Restrict allowed locations.
- Require tags.
- Enforce approved SKUs or settings.

## Exam Focus

- Policy enforces or audits rules.

Azure Policy helps enforce standards and assess compliance across Azure resources. It can block non-compliant deployments or audit them for remediation.

## What It Does

- Enforces governance rules.
- Audits existing resources.
- Can apply settings at scale in some scenarios.

## Common Uses

- Restrict allowed regions.
- Require tags.
- Enforce SKU or configuration standards.

## Exam Focus

- Azure Policy is for governance and compliance.
- It is different from RBAC, which controls permissions.
