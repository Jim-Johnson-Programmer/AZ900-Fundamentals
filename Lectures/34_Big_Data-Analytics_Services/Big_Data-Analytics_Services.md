# Big Data and Analytics Services

Big data and analytics services help organizations store, process, and analyze large volumes of data. In AZ-900, the goal is to recognize the type of problem these services solve rather than their full implementation details.

## Typical Use Cases

- Analyzing very large data sets.
- Combining data from many systems.
- Running dashboards, reports, and large-scale transformations.

## Common Azure Services

- Azure Synapse Analytics for enterprise analytics.
- HDInsight for managed open-source big data frameworks.
- Data Lake services for large-scale storage and analytics workflows.

## Exam Focus

- Big data services are for scale and analysis, not basic transactional storage.

Big data and analytics services help store, process, and analyze very large datasets. These services are often used for reporting, machine learning pipelines, and business intelligence.

## Typical Needs

- Process large volumes of data.
- Perform batch or streaming analytics.
- Build dashboards and insights from data.

## Common Azure Services

- Azure Synapse Analytics for enterprise analytics.
- Azure Databricks for data engineering and analytics.
- HDInsight in scenarios needing managed open-source big data tooling.

## Exam Focus

- Recognize Synapse Analytics and Databricks as major analytics services.
- Big data services are chosen when scale and analytics complexity exceed standard database scenarios.
