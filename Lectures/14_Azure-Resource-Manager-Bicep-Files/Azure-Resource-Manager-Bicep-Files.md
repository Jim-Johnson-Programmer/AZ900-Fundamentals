# Azure Resource Manager and Bicep Files

Azure Resource Manager, or ARM, is the deployment and management layer for Azure. Bicep is a domain-specific language that simplifies authoring Azure infrastructure as code.

## Azure Resource Manager

- Provides consistent deployment and management APIs.
- Supports templates for repeatable deployments.
- Enables role-based access control, policy enforcement, and tagging.

## Bicep

- Offers cleaner syntax than raw ARM JSON templates.
- Compiles to ARM templates.
- Makes infrastructure deployments more readable and maintainable.

## Why This Matters

- Infrastructure can be versioned, reviewed, and redeployed consistently.
- Manual portal configuration is reduced.
- Standardization improves governance and repeatability.

## Exam Focus

- ARM is the control plane for Azure resource deployment.
- Bicep is used to define infrastructure declaratively.
- Templates help automate consistent deployments.
