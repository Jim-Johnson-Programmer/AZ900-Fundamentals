# Virtual Machines

Azure Virtual Machines provide on-demand, scalable compute resources using infrastructure as a service. They give customers strong control over the operating system and application stack.

## When to Use Virtual Machines

- Running custom software or legacy applications.
- Migrating on-premises servers with minimal redesign.
- Needing full OS access and control.

## Benefits

- Flexible sizing options.
- Support for Windows and Linux workloads.
- Can be combined with load balancers, availability sets, and availability zones.

## Tradeoffs

- More management responsibility than PaaS offerings.
- You are responsible for patching, configuration, and much of the operating system maintenance.

## Exam Focus

- Virtual machines are an IaaS offering.
- They provide more control than App Service or Functions.
- They are appropriate when OS-level access is required.
