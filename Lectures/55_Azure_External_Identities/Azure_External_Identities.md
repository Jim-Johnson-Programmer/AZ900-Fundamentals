# Azure External Identities

External identities let organizations collaborate with users outside their own directory, such as partners, vendors, customers, or guests.

## Why It Matters

- Modern systems often need secure access for people outside the company.
- External identity features reduce the need to create unmanaged local accounts.

## Exam Focus

External identities allow people outside your organization to access applications and resources in controlled ways. This is common for partners, guests, and customer-facing identity scenarios.

## Common Scenarios

- B2B collaboration with partner users.
- Controlled guest access.
- External user sign-in experiences.

## Why It Matters

- Organizations often need collaboration beyond internal employees.
- External access still needs governance and security controls.

## Exam Focus

- External identities support collaboration and external user access.
- They are part of identity strategy, not a separate network security feature.
