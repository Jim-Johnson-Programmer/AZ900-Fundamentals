# Azure Dedicated Hosts

Azure Dedicated Host provides a physical server dedicated to one organization. This can help with compliance, licensing, or workload isolation requirements.

## Why Use It

- Meet regulatory or compliance demands.
- Gain visibility and control over physical host allocation.
- Support certain licensing scenarios.

## Tradeoffs

- More specialized and usually more expensive than shared infrastructure.
- Not needed for most general-purpose AZ-900 scenarios.

## Exam Focus

- Dedicated Host is about physical server isolation.
