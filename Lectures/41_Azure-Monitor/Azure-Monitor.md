# Azure Monitor

Azure Monitor collects and analyzes telemetry from Azure and hybrid resources. It helps track performance, availability, logs, and alerts.

## What It Collects

- Metrics such as CPU, memory, and request counts.
- Logs from resources and applications.
- Diagnostic data for troubleshooting.

## Common Uses

- Build alerts for important conditions.
- Investigate operational issues.
- Observe application and infrastructure health.
