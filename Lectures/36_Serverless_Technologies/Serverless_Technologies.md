# Serverless Technologies

Serverless technologies let you run code or workflows without managing the underlying servers. Azure handles provisioning, scaling, and much of the infrastructure maintenance.

## Benefits

- Fast development and deployment.
- Automatic scale behavior.
- Billing based on use rather than always-on capacity in many cases.

## Azure Examples

- Azure Functions for event-driven code execution.
- Logic Apps for workflow automation and integrations.

## Exam Focus

- Serverless does not remove servers; it removes server management from your responsibilities.
