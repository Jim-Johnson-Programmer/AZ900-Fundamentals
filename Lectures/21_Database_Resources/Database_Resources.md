# Database Resources

Azure provides multiple database services for relational, NoSQL, and specialized data workloads. AZ-900 focuses on knowing which broad database option fits a scenario.

## Relational Databases

- Azure SQL Database for managed relational workloads.
- Azure Database for PostgreSQL and Azure Database for MySQL for open-source relational engines.

## NoSQL and Specialized Databases

- Azure Cosmos DB for globally distributed NoSQL workloads.
- Other services may support analytics, caching, or big data use cases.

## Choosing a Database Service

- Use relational databases for structured data and SQL querying.
- Use NoSQL when flexible schema, global distribution, or very high scale is important.
- Choose managed services to reduce administrative overhead.

## Exam Focus

- Know the difference between relational and non-relational databases.
- Recognize Azure SQL Database and Azure Cosmos DB as key services.
- Match the database model to the application need.
